# 实机 1 米悬停与降落操作

## 目标

本流程只执行以下动作：

1. 实机起飞到约 1 m；
2. 保持定点悬停；
3. 人工确认悬停稳定后发送降落命令；
4. PX4 进入 `AUTO.LAND`，落地后自动上锁。

本流程不执行轨迹。全程不要运行 `pub_trigger.sh`。

## 安全前提

- 在隔离场地进行，首次有桨测试建议系留。
- 由一名飞手持遥控器，全程保持可人工接管。
- 确认参数中的飞机质量、悬停油门与实机一致：
  `src/ctrl_node/config/ctrl_param.yaml`。
- 当前起飞参数为 `height: 1.0` m、`speed: 0.3` m/s。
- 当前状态机在目标高度以下 0.1 m 内会转入悬停，因此实际悬停高度约为 0.9–1.0 m。
- 不要在空中关闭 MAVROS、odomRemap、controller 或规划器终端。
- 空中按 `Ctrl+C` 不等于安全降落。

## 操作流程

### 1. 启动实机控制链路

飞机保持未解锁、非 `OFFBOARD` 模式。在启动终端执行：

```bash
cd ~/HAM_Flight
bash sh_utils/RTK_realflight_traj_follow.sh
```
sudo chmod 666 /dev/ttyACM0

等待终端显示全部 `READY`，并确认没有 `FATAL`。启动脚本会检查 MAVROS、RTK Fixed、PX4 EKF、`/odom/remap`、控制器输出和 Offboard 丢失保护。

### 2. 准备操作终端

`takeoff` 和 `land` 在同一个操作终端中依次输入。

如果启动脚本显示 `READY` 后已经返回 shell 提示符，可以继续使用该终端。也可以新开一个终端，并先执行：

```bash
cd ~/HAM_Flight
source /opt/ros/noetic/setup.bash
source devel/setup.bash
```

### 3. 切入 OFFBOARD

由飞手使用外部遥控器切入 `OFFBOARD`。

真机不要运行：

```bash
bash sh_utils/set_offboard.sh
```

可以检查 PX4 状态：

```bash
rostopic echo -n 1 /mavros/state
```

起飞命令发送前应看到：

```yaml
connected: True
armed: False
mode: "OFFBOARD"
```

### 4. 起飞并悬停

切入 `OFFBOARD` 后，立即在操作终端输入：

```bash
bash sh_utils/takeoff.sh
```

控制器会请求解锁，随后爬升到约 1 m，并自动从 `TAKEOFF` 转入 `HOVER`。

不要运行以下命令：

```bash
bash sh_utils/pub_trigger.sh
```

该命令会触发轨迹任务。

### 5. 观察悬停

可在其他终端观察位置：

```bash
rostopic echo /odom/remap/pose/pose/position
```

观察速度：

```bash
rostopic echo /odom/remap/twist/twist/linear
```

至少稳定观察数秒，确认：

- 高度约为 0.9–1.0 m；
- 没有持续水平漂移；
- 没有明显振荡或高度发散；
- RTK/EKF 没有异常报警；
- 遥控器接管开关仍然有效。

### 6. 在同一操作终端降落

确认悬停稳定后，在刚才执行 `takeoff.sh` 的同一个终端输入：

```bash
bash sh_utils/takeland.sh
```

脚本会检查飞机仍为已解锁的 `OFFBOARD` 飞行，然后发送降落命令。控制器将降落交给 PX4 `AUTO.LAND`。

`LAND accepted` 只代表 PX4 已开始接管降落，不代表已经落地。

### 7. 确认落地和上锁

执行：

```bash
rostopic echo -n 1 /mavros/state
rostopic echo -n 1 /mavros/extended_state
```

最终必须确认：

```yaml
armed: False
landed_state: 1
```

只有在确认已上锁且 `LANDED_STATE_ON_GROUND` 后，才能靠近飞机。

## 异常处理

出现以下任一情况时，立即使用遥控器退出 `OFFBOARD`，并按现场预案接管或降落：

- 飞机水平快速漂移；
- 持续振荡；
- 高度异常或持续爬升；
- 飞行方向与控制预期不一致；
- RTK 丢失 Fixed；
- PX4 EKF 或 MAVROS 报警；
- 控制器、里程计或通信中断。

`takeland.sh` 是辅助降落命令，不能替代遥控器人工接管和 PX4 独立 failsafe。
